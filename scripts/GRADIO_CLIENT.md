# 🤖 Gradio клиент для Personal AI Platform

Интерактивный веб-интерфейс для взаимодействия с Personal Multi-Agent AI Platform.

## 📋 Возможности

- ✅ **Управление агентами**: создание, просмотр, удаление персональных агентов
- ✅ **Чат-сессии**: создание сессий и отправка сообщений
- ✅ **Прямой вызов агентов**: обход оркестратора для быстрых запросов
- ✅ **SSE события**: real-time мониторинг событий системы
- ✅ **История чата**: просмотр всех сообщений в сессии
- ✅ **JWT аутентификация**: безопасное подключение к API

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Установить зависимости для Gradio клиента
pip install -r scripts/requirements-gradio.txt

# Или с использованием uv
uv pip install -r scripts/requirements-gradio.txt
```

### 2. Генерация JWT токена

```bash
# Сгенерировать тестовый JWT токен
python scripts/generate_test_jwt.py

# Вывод:
# JWT Token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
# User ID: 123e4567-e89b-12d3-a456-426614174000
```

### 3. Запуск сервиса (в отдельном терминале)

```bash
# Запустить FastAPI сервис
uv run uvicorn app.main:app --reload

# Сервис будет доступен на http://localhost:8000
```

### 4. Запуск Gradio клиента

```bash
# Запустить Gradio интерфейс
python scripts/gradio_ui.py

# Или с переменными окружения
export API_BASE_URL="http://localhost:8000"
export JWT_TOKEN="your_jwt_token_here"
python scripts/gradio_ui.py
```

Интерфейс будет доступен на: **http://localhost:7860**

## 📖 Использование

### Шаг 1: Инициализация

1. Откройте вкладку **"🔐 Инициализация"**
2. Вставьте JWT токен (полученный из `generate_test_jwt.py`)
3. Нажмите **"🚀 Инициализировать клиент"**
4. Дождитесь подтверждения: `✅ Клиент инициализирован`

### Шаг 2: Создание агента

1. Перейдите на вкладку **"👥 Агенты"**
2. Заполните форму:
   - **Имя агента**: "Мой программист"
   - **System Prompt**: "Ты опытный Python разработчик"
   - **Provider**: "openai"
   - **Model**: "gpt-4o-mini"
3. Нажмите **"➕ Создать агента"**
4. Скопируйте `agent_id` из ответа (например: `user123e4567_agent_v1`)

### Шаг 3: Создание чат-сессии

1. Перейдите на вкладку **"💬 Чат"**
2. Нажмите **"➕ Создать сессию"**
3. Запомните `Session ID` (например: `1`)

### Шаг 4: Отправка сообщения

**Вариант A: Через оркестратор (автоматический выбор агента)**

1. Введите **Session ID**: `1`
2. Введите **Сообщение**: "Напиши функцию для сортировки списка"
3. Оставьте **Target Agent** пустым
4. Нажмите **"📤 Отправить"**

**Вариант B: Прямой вызов агента (быстрее)**

1. Введите **Session ID**: `1`
2. Введите **Сообщение**: "Что такое list comprehension?"
3. Введите **Target Agent**: `user123e4567_agent_v1`
4. Нажмите **"📤 Отправить"**

### Шаг 5: Мониторинг SSE событий

1. Перейдите на вкладку **"📡 SSE События"**
2. Введите **Session ID**: `1`
3. Нажмите **"▶️ Запустить SSE listener"**
4. Периодически нажимайте **"🔄 Обновить события"** для просмотра новых событий

## 📡 SSE События

Клиент поддерживает следующие типы событий:

| Событие | Описание |
|---------|----------|
| `direct_agent_call` | Прямой вызов агента (обход оркестратора) |
| `agent_status_changed` | Изменение статуса агента (ready/busy/error) |
| `task_plan_created` | Оркестратор создал план выполнения |
| `task_started` | Задача начала выполняться |
| `task_progress` | Промежуточный прогресс (0-100%) |
| `task_completed` | Задача завершена с результатом |
| `tool_request` | Запрос на подтверждение использования tool |
| `plan_request` | Запрос на подтверждение плана |
| `approval_required` | Требуется действие пользователя |
| `context_retrieved` | Использован RAG контекст из Qdrant |

**Пример события:**
```json
{
  "event_type": "task_completed",
  "payload": {
    "task_id": "task_abc123",
    "result": "Функция успешно создана",
    "duration": 2.5,
    "timestamp": "2026-02-12T16:00:00Z"
  },
  "session_id": "1",
  "timestamp": "2026-02-12T16:00:00Z"
}
```

## 🔧 Troubleshooting

### Проблема: "❌ Сначала инициализируйте клиент с JWT токеном"

**Решение:**
1. Перейдите на вкладку "🔐 Инициализация"
2. Вставьте валидный JWT токен
3. Нажмите "🚀 Инициализировать клиент"

### Проблема: "❌ Ошибка: 401 Unauthorized"

**Решение:**
1. Проверьте, что JWT токен валиден
2. Сгенерируйте новый токен: `python scripts/generate_test_jwt.py`
3. Убедитесь, что токен содержит claim `"sub"` с user_id

### Проблема: "❌ Ошибка: Connection refused"

**Решение:**
1. Убедитесь, что FastAPI сервис запущен: `uv run uvicorn app.main:app --reload`
2. Проверьте, что сервис доступен: `curl http://localhost:8000/health`
3. Проверьте `API_BASE_URL` в конфигурации

### Проблема: SSE события не приходят

**Решение:**
1. Убедитесь, что SSE listener запущен
2. Проверьте, что Session ID правильный
3. Отправьте сообщение в чат для генерации событий
4. Нажмите "🔄 Обновить события" для получения новых событий

### Проблема: "❌ Ошибка: 403 Forbidden"

**Решение:**
1. Проверьте, что `agent_id` принадлежит вашему пользователю
2. Agent ID должен начинаться с `user{user_id}_`
3. Используйте "📋 Список агентов" для просмотра доступных агентов

## 🚀 Расширенные возможности

```bash

# Запустить Gradio клиент
export API_BASE_URL="http://localhost:8000"
python scripts/gradio_ui.py
```

```bash

export API_BASE_URL="https://api.example.com"
export JWT_TOKEN="your_production_token"
python scripts/gradio_ui.py
```

### Публичный доступ (Gradio Share)

Отредактируйте [`scripts/gradio_ui.py`](gradio_ui.py:569):

```python
app.launch(
    server_name="0.0.0.0",
    server_port=7860,
    share=True,  # Включить публичный доступ
    show_error=True
)
```
